Entry for the [Rejected Olympic Sports](https://make.fun/c/u-motasimfuad-rejected-olympic-sports-9d83e7da) bounty on make.fun: one funny single-line sport the Olympics rejected.

## The entry

> Competitive Apologising: two athletes collide in a hotel corridor and must out-sorry each other until one cracks and says 'No, MY fault' — instant disqualification.

## How it works

`main.py` (pure Python standard library, no dependencies) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`), deterministically and with world-readable `0644` permissions, so the grader can read it whatever directory it runs from.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
